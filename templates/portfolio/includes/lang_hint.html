{% comment %} Language hint. Tells a first-time visitor that the page exists in their browser's language, written in that language rather than the page's. Unprefixed URLs already follow the browser's language, so this is for the visitor who opens a link to one language with a browser set to the other (a shared /es/ link, for instance). It is a small dark popover with a caret pointing at the language switcher, not a banner, so it stays out of the way of the page. The switcher is rendered more than once (mobile header, top bar or floating corner) and only one copy is visible, so the script anchors to whichever one has a box. Not rendered once the visitor has picked a language with the switcher. Otherwise rendered hidden: the script shows it only when the browser's preferred language is the other one, a moment after load, keeps it for a few seconds (paused while hovered, focused or touched) and fades it out by itself. It is remembered in localStorage as seen when it is closed, used, or has timed out, so it does not come back on every page.
