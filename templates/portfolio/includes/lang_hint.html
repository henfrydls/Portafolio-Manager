{% comment %} Language hint. Tells a first-time visitor that the page exists in their browser's language, written in that language rather than the page's. Unprefixed URLs already follow the browser's language, so this is for the visitor who opens a link to one language with a browser set to the other (a shared /es/ link, for instance). Not rendered once the visitor has picked a language with the switcher. Otherwise rendered hidden: the script at the end shows it only when the browser's preferred language is the other one, and remembers in localStorage that it was closed or used, so it never comes back.
